# 📊 Project Overview

This project analyzes **user engagement, performance metrics, and uninstall behavior** in a mobile gaming application.
The interactive dashboards provide insights into how **device specifications, app versions, crashes, and session behavior influence user retention and uninstall rates**.

The goal is to help **product teams and developers identify performance issues and improve user retention strategies** through data-driven insights.

---

# 🎯 Business Problem

Gaming companies face challenges in maintaining **high user retention** due to:

• Device performance issues
• App crashes and instability
• Poor optimization for different RAM configurations
• Version update performance differences

Without proper analytics, it becomes difficult to **identify the root causes behind app uninstall behavior**.

---

# 🎯 Project Objective

The main objective of this project is to design **interactive analytics dashboards** that:

• Monitor gaming app performance metrics
• Identify key drivers of uninstall behavior
• Analyze device-level performance impact
• Track user engagement patterns
• Support data-driven retention strategies

# 📊 Dashboard 1 — Gaming App Insights & Performance Metrics

![Dashboard1](Dashboard/Page1_Dashboard.jpeg)

### Key Metrics

• Total Users
• Active Users
• Average FPS Performance
• Average Session Duration
• Crash Rate
• App Uninstall Count

### Key Insights

• Samsung devices represented the highest user distribution.
• Certain app versions showed significantly higher uninstall rates.
• Peak uninstall trends occurred during longer uninstall session windows.
• Device models with higher crash counts had increased uninstall behavior.
